# Quaternius Universal Animation Libraries (free Standard editions)

Imported from the official itch.io downloads on 2026-10-06 using the free $0 option. No payment or supporter tier was selected.

- `UAL1_Standard.glb` — 43 clips, including `Punch_Jab`, `Punch_Cross`, hit reactions, crouch and jump clips.
- `UAL2_Standard.glb` — 43 clips, including `Melee_Hook`, `Melee_Hook_Rec`, `Hit_Knockback`, `LayToIdle`, and jump start/land clips.
- Both archives mark their contents CC0 1.0; the accompanying license texts are preserved here.
- Use the no-root-motion (`*_Standard.glb`) variants. Fighter displacement is controlled by the game, so importing root-motion variants would move each fighter twice.
- The paid Source/Pro versions and their extra files were not downloaded or used. Sword animations are not intended for the current bare-hand moveset.

Sources: [Universal Animation Library](https://quaternius.itch.io/universal-animation-library), [Universal Animation Library 2](https://quaternius.itch.io/universal-animation-library-2).
